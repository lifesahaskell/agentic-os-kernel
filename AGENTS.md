# agentic-os-kernel

Research workspace for scoping a natively agentic, POSIX-adherent operating system (formal
certification dropped 2026-10-23). Three layers:

- `wiki/`: an LLM-maintained wiki compiled from the sources in `raw/`. Its `[[wikilinks]]` form the
  knowledge graph.
- `docs/architecture/`: scoping documents and ADRs. They cite wiki pages; they do not copy them.
- `kernel/`: the B2 spike, capability-microkernel primitives on Asterinas OSTD 0.19.0
  ([report](docs/architecture/b2-spike-report.md)).

## Layout

| Path | What | Who edits |
|------|------|-----------|
| `raw/` | Source PDFs + `raw/text/*.txt` (pdftotext, page-marked). Gitignored: copyrighted and derived. | Humans add sources; never edited |
| `wiki/sources/<slug>.md` | One summary page per source | LLM |
| `wiki/concepts/<slug>.md` | One page per concept, merged across sources | LLM |
| `wiki/index.md` | Catalog of every page, one line each, grouped | LLM, on every ingest |
| `wiki/log.md` | Append-only record of ingests and lint passes | LLM, append only |
| `wiki/graph.json` | Generated by `tools/wikigraph.py`; do not hand-edit | Tool |
| `tools/wikigraph.py` | Builds `graph.json`, reports broken links and orphans | Humans |
| `kernel/` | OSTD kernel crate. Build image: `docker build -t agentic-os-kernel-dev:0.19.0 kernel`; then from `kernel/`: `./osdk.sh cargo osdk test` (ktests in QEMU), `./osdk.sh cargo osdk run`, `./osdk.sh cargo osdk clippy`, `./osdk.sh cargo fmt --check` | Humans and LLM |

`raw/` is not in git. To rebuild it on a fresh clone, put the PDFs in `raw/` and see the ingest
steps below.

## Page conventions

- File name = slug: lowercase kebab-case, unique across the whole wiki (links do not carry a
  folder).
- Frontmatter:
  ```yaml
  ---
  title: Human Name
  type: concept | source
  sources: [ostep, aios]          # source slugs this page draws on
  tags: [virtualization]          # virtualization | concurrency | persistence | distribution | security | agentic
  ---
  ```
- Body: a one-paragraph definition, then `## Mechanisms` (bullets), `## Trade-offs`,
  `## Agentic OS relevance`, `## Related`.
- **Every factual claim cites a page**: `(ostep p. 123)` or `(aios p. 5)`. These are **PDF page
  numbers**, matching the `=== PDF page N ===` markers in `raw/text/`, not the book's printed page
  numbers.
- Our own reasoning (anything not stated by a source) goes under `## Agentic OS relevance` or is
  marked *(interpretation)*. Never present it as the source's claim.
- Link concepts with `[[slug]]` or `[[slug|label]]`. Link the first mention on a page, not every
  mention.

## Workflows

**Ingest a new source**
1. Put the PDF in `raw/`. Run `pdftotext -layout raw/X.pdf raw/text/X.txt`, then split it into page-marked
   chunks of 100-200 pages (see `wiki/log.md` for the ranges used last time).
2. Extract one chunk per subagent (a mid-tier model is fine), writing candidate concepts with page
   refs to a scratch file, not to the wiki.
3. Merge into `wiki/`: update existing concept pages before creating new ones; add
   `wiki/sources/<slug>.md`; update `wiki/index.md`; append to `wiki/log.md`.
4. Lint (below).

**Query**: read `wiki/index.md` first, then the linked pages. Answer with page citations. If the
answer is worth keeping, file it as a new page and link it.

**Lint**: `python3 -I tools/wikigraph.py wiki` must exit 0 (no broken links). Orphans are allowed
but each one should be linked from at least `index.md`. Check a sample of citations against
`raw/text/`.

## Source notes

- `aios`: `raw/aios-rutgers-2026-03.pdf` is arXiv 2403.16971 **v2 (March 2024)**, despite the
  filename. Later AIOS versions exist and are not ingested.
- `ostep`: *Operating Systems: Three Easy Pieces*, Arpaci-Dusseau, 829-page PDF including
  Reiher's security chapters. Concept pages only, no per-chapter pages (decided 2026-10-23).
