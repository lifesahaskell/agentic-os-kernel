**User story (MVP):** **As** the researcher, **I want to** measure BPF-LSM cost and the same-uid broker attack on a named privileged reference host and record my acceptance of S1-S9, **so that** the cheapest ADR 0004 falsifiers are read before any prototype component is built.

<objective>
Build the `tools/aok-adv` Rust adversarial suite and stub broker: the ADV-01 S1 case skeleton (one valid case per class), the ADV-02 S5 attempt set against a stub broker (kill, signal, ptrace, bind, impersonation), and the ADV-03 route enumeration with per-route JSON and a deny-counter merge. The suite targets the broker by pid and socket path only (D-14), so it runs unchanged against the real Phase 10 broker (ADV-05). All `unsafe` sits in one `src/sys.rs` module (D-13); the crate is test tooling outside the TCB.

Purpose: the S5 same-uid attack is one of the three cheapest ADR 0004 falsifiers. The non-agent baseline run (every attempt succeeds) proves each route reaches a real path, which is the precondition for reading the agent-cgroup counts in 08-05. The code is L-buildable today; only the agent-cgroup and delegated-cgroup runs need the reference host.

Output: the `tools/aok-adv` crate with `stub`, `run`, `list-routes` and `report` subcommands, the pinned toolchain, and a `cargo test` that exercises the stub protocol and the route table.

**Assumption-delta note (no-change):** The "fallback" referenced across this phase is the D-11 global ancestor-id BPF program, a measured alternative to the per-cgroup config, not a second identity model. The stub here uses exactly one identity model: the kernel-stamped cgroup id (D-15).

**Host labels:** **Task 1 (tracer) is L** — the crate, `src/sys.rs`, the stub identity reply, and the `kill` route run non-agent with `--no-cgroup`, all verifiable on WSL2 via `cargo test`, fmt and clippy. **Tasks 2 and 3 are L for build/test** (the route table, safety guards, cases, report all compile and unit-test on WSL2); their agent-cgroup and delegated-cgroup execution is **R** and happens in 08-05, marked `skipped: needs delegated cgroup` under `--no-cgroup` here.

**D-03 sequencing note:** If the reference host is not up by 2026-11-04, Phases 9 and 10 run first. This crate builds and unit-tests independently of the host; its R execution in 08-05 is cleanly separable.
