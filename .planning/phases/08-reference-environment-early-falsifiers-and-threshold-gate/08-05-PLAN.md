**User story (MVP):** **As** the researcher, **I want to** measure BPF-LSM cost and the same-uid broker attack on a named privileged reference host and record my acceptance of S1-S9, **so that** the cheapest ADR 0004 falsifiers are read before any prototype component is built.

<objective>
Run the three measurement campaigns on the reference host: HARN-01 (the four-suite C0-C3 transfer run behind S3/S4/S6), HARN-02 + HARN-03 (the BPF-LSM variant costs and the lsm_cgroup attach), and ADV-01/02/03 (the S1 adversarial suite, the baseline and the agent-cgroup run). Every task here is **R** and executes the wrapper and suite the earlier plans authored; the human launches the runs, and the agent reads back and checks with exit-status gates.

Purpose: these are the actual falsifier measurements. HARN-02/03 decide ADR 0004 decision 2 (can per-cgroup BPF-LSM carry the identity at acceptable cost); ADV-02/03 are the same-uid broker attack. The validity lines are the proof the hooks fired on the right path; the transfer verdicts say whether the WSL2 numbers transfer to the reference host.

**No L tracer in this plan.** Every step needs the reference host (Task 1 needs no root but needs the host and, under OQ2 yes, its no-bpf boot entry; Tasks 2 and 3 need root, `bpftool` and a bpf-in-LSM kernel). The phase-level tracers are 08-01 Task 1 (r1 self-test) and 08-03 Task 1 (the wrapper dry-run); this plan consumes those proven artifacts. All three tasks are `checkpoint:human-action`, `autonomous: false`.

**Fixed run ids:** ref-harn01, ref-harn01-bpfboot (OQ2 yes only), ref-bpflsm-global-miss, ref-bpflsm-global-hit, ref-bpflsm-global-miss-nocount, ref-bpflsm-anc (only if the lsm_cgroup attach fails), ref-harn03 under tools/linux-baseline/results/, and ref-adv under tools/aok-adv/results/. 08-06 cites these names.

**Assumption-delta note (no-change):** The "fallback" is the D-11 global ancestor-id program (the `anc` variant), a measured alternative to the per-cgroup `lsm_cgroup` config, run only if the `lsm_cgroup` attach fails, not a second identity model.

**D-03 sequencing note:** If the reference host is not up by 2026-11-04, all three tasks stay blocked behind 08-04's open human-action checkpoint; Phases 9 and 10 run first and ADR 0004 decision 2 is reported untested.
</objective>
