**As a** server author, **I want to** have a Rust ring-3 toolchain, a fuzz-safe syscall ABI and call/reply IPC, **so that** servers can run and the IPC cost is known.

<objective>
Replace the run loop's raw-register `match` with a typed decode layer in `kernel/src/syscall.rs` (KERN-02), route every kernel write into user memory through one CoW-breaking `copy_to_user` (KERN-06), and prove the boundary with a seeded fuzz ktest plus a ring-3 malformed-syscall program.

Purpose: IPC v2 (01-05, 01-06) adds the bulk-copy and cap-transfer syscalls, so it must land on a validated boundary and a single write path into user memory.
Output: `syscall.rs`, `vm::copy_to_user`/`copy_from_user`, the fuzz ktest, and `badsys`.
</objective>

  <action>
    **vm.rs.** Add both functions. Each requires `space` to be the active space; debug-assert that.

    `pub fn copy_to_user(space: &VmSpace, agent: &Agent, dst: UserSlice, src: &[u8]) -> Result<(), Errno>`:
    1. Write through the fallible `VmSpace` writer.
    2. On a fault, compute the faulting page from the bytes already written.
    3. Call `handle_cow_fault(space, agent, addr)`.
    4. Retry from that offset.
    5. Return EFAULT for `Ok(false)` (not CoW) or after 2 CoW breaks on the same page, and ENOMEM when the agent's budget refuses the copy.

    `pub fn copy_from_user(space: &VmSpace, dst: &mut [u8], src: UserSlice) -> Result<(), Errno>`: use the fallible reader; any fault is EFAULT.

    A `UserPtr<T>` read or write goes through these two functions. For `IpcArgs`, add safe `to_bytes(&self) -> [u8; 168]` and `from_bytes(&[u8; 168]) -> Self` to `abi`, which encode the fields in order as little-endian `u64`s. The kernel takes no `zerocopy` dependency.

    **ipc.rs.** Migrate `ipc::sys_call` to `copy_from_user` and `copy_to_user` (KERN-06). After this task, no file other than `vm.rs` calls `.writer(` on a `VmSpace` or on a user-mapped frame. The loaders' `write_bytes` on fresh, unmapped frames stay as they are.

    Write the ktests in `vm.rs` (or `user.rs`'s test module if they need its helpers) first.
