  <files>userland/tests/src/bin/nullsrv.rs, userland/tests/src/bin/nullipc.rs, userland/libsys/src/lib.rs, kernel/src/ipc.rs, docs/architecture/ipc-measurements.md, docs/architecture/unsafe-ledger.md</files>

  <action>
    Per IPC-06 and the user decision (report only, no ceiling), write two bins.

    **nullsrv** (`arg` = the RECV slot): `recv` once, then loop `reply_recv` with zero words, no data and no caps.

    **nullipc** (`arg` = the SEND slot to nullsrv; `arg + 1` = a SEND slot to the kernel report endpoint):
    1. Make 1,000 warm-up null calls.
    2. Time 10,000 calls one at a time with `rdtsc` around each, storing cycle deltas in a `static` `.bss` `[u64; 10_000]`.
    3. Sort with `sort_unstable`.
    4. Send `[n, median, p99, max]` to the report endpoint with `call`, where median is element 5,000 and p99 is element 9,900.
    5. Exit 0.

    `rdtsc` comes from `core::arch::x86_64::_rdtsc`. If that is `unsafe` on the pinned nightly, wrap it in `libsys::tsc()` as ledger U-05; otherwise add no ledger entry.

    **ktest `null_ipc_round_trip_is_recorded`** in `ipc.rs`:
    - Run both bins on two threads of separate root agents, with a kernel thread answering the report.
    - Print `aok: null-ipc n=10000 median=<m> p99=<p> max=<x> cycles`, followed by the TSC frequency line if OSTD exposes one (`ostd::arch::tsc_freq` or the equivalent the executor finds; omit it otherwise and say so).
    - Assert only `n == 10_000` and `median > 0`.

    **docs/architecture/ipc-measurements.md** records:
    - date, commit, host CPU (`/proc/cpuinfo` model name, read on the host), and QEMU/KVM flags (`-smp 1`);
    - the method (warm-up, N, statistic indices) and the numbers from the ktest output;
    - a one-line comparison against the B2 spike's IPC figure if `b2-spike-report.md` has one, cited by section.

    Mark any reasoning not measured as *(interpretation)*.
  </action>
