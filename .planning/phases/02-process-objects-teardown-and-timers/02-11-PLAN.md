    Per D-03 (a settle loop before the second count absorbs RCU-delayed frees) and D-06. The settle length is Claude's discretion under 02-CONTEXT.md, calibrated by this task's log.

    **`pub const SETTLE_ROUNDS: usize = 8;`** Its doc comment says the value is calibrated: the SUMMARY records the logged curve. Raise the constant if the 16-round line shows a smaller delta than the 8-round line.

    **`pub fn settle(rounds: usize)`.**
    - Each round spawns a no-op peer kernel task through `TaskOptions::new(closure).spawn()`.
    - The task gets no task data, so `sched::eligible` always admits it.
    - Its closure stores true into a shared `Arc<AtomicBool>` with `Release`.
    - The caller loops on `Task::yield_now()` until the flag loads true with `Acquire`.
    - Each round forces at least two real task switches, which is where OSTD advances RCU grace periods. A bare yield with no other runnable task switches nothing (Pitfall 16).

    **`pub fn park_activation()`.**
    - Keep a `static PARK: SpinLock<Option<Arc<VmSpace>>, LocalIrqDisabled>`, initialised with `SpinLock::new(None)` like `futex::TABLE` and `thread::DEADLINES`.
    - Take the lock, `get_or_insert_with` a fresh `Arc::new(VmSpace::new())`, clone the Arc, release the lock, then `activate()` the clone.
    - The dummy is created once and never mapped, so it pins the same root frame during every read.
    - Activating it releases whatever space the slot pinned before (Pitfall 3).

    **`pub fn settled() -> usize`.** Calls `park_activation()`, then `settle(SETTLE_ROUNDS)`, then returns `free()`. This is the one probe protocol the gates in 02-07 and 02-09 call before each read they compare. The module doc states the protocol as park, settle, read.
