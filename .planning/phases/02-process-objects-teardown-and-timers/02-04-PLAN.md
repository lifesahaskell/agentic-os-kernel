**As a** procmgr author, **I want to** have Space and Thread capabilities, full process teardown and timers, **so that** processes can be created, signalled and destroyed without leaks.

<objective>
Make the process a kernel object (KERN-04): `Object::Space` and `Object::Thread` capabilities, and a `thread_create(space, ctx, tag)` gated by the Space capability's CREATE right, plus `thread_interrupt` gated by the Thread capability's SIGNAL right.

This plan is a DRAFT written against the post-01-07 tree (OD-10), on top of 02-01 and 02-02. Re-check after 01-07 lands:
- Task 1: the `spinner` image's entry, handler and exit code. 01-07 replaces `user::prog` with it, so the expected exit code is whatever its handler exits with, and the plan assumes the interrupted pc. Also the testkit helpers 01-07 leaves in `user.rs`.
- Task 2: `abi` after 01-07 (it adds `TEST_DATA`) and after 02-02 (`Timespec`, `SYS_TIMER_ARM`, the label range). Use the next free lines, and the post-02-02 fuzz `targeted` array length.
- Task 3: the fuzz test's free scratch offset below `mapped`. 02-02 uses `mapped + 64`, so this plan takes `mapped + 128`; confirm nothing writes there before the targeted cases.

Decisions this plan rests on:
- OD-11: promote Space, with the invariant tested.
- OD-13: tag rules.

- The syscall table rows 0x104 and 0x105, the ThreadCtx layout, CREATE = 8, SIGNAL = 16, ALL = 31 and ESRCH = 3, all in `02-OPEN-DECISIONS.md`.

Purpose: procmgr (Phase 4) creates processes by holding Space capabilities. Every later Phase 2 plan (notifications, teardown, signal frames, mmap) hangs per-process state off this object.

<assumption_delta_decision id="OD-11">
- Noun now primary: the process, as kernel object `space::Space`.
  - Research models a process as "a VmSpace plus the threads that run in it", with the agent reachable only through each thread.
  - Phase 2 adds per-process state: a notify endpoint (02-05), a charge ledger and a dying flag (02-06), and mappings and brk (02-09). It also adds a second way for a thread to come into being (`thread_create` in another space).
- Decision: **promote**.
  - `Space { vm, owner, threads }` is the identity the Space capability names.
  - `Thread` holds `Arc<Space>`.
  - The raw `VmSpace` becomes a detail reached through `Space::vm()`.
  - `Thread::space()` keeps returning the `VmSpace`, so `sched.rs` and `futex.rs` do not change.
- Invariant test: `space_credential_matches_owner` asserts that every thread started by any path (`start`, `run`, `thread_create` with a slot, `thread_create` with `SPACE_SELF`) has `agent().credential() == space.owner().credential()`. A later phase that lets a thread run with another agent turns it red.
- What would force a re-think: a ktest finds a strong cycle that the 02-07 drain does not break, so `SPACE_OBJECTS` climbs in the 10,000x loop. That is the OD-14 falsifier.
</assumption_delta_decision>

    **`thread_create(caller, target, start, tag, publish)`.** Checks run in this order, so the errno for a call with several faults is fixed:
    1. `start` fields. `rip` and `rsp` must lie in `[PAGE_SIZE, USER_TOP)`, and `fs_base` below `USER_TOP`; otherwise `Invalid`. The kernel must never return to a non-canonical pc. A non-zero `clear_tid` is `Invalid` until 02-10 gives it its exit behaviour, which lifts this check.
    2. The tag rule. `SelfSpace` with a non-zero tag is `Invalid`. Otherwise `SelfSpace` uses `caller.tag()` (OD-13).
    3. The target.
       - `SelfSpace` is `caller.process()`, or `Dead` when the caller has none.
       - `Slot(s)` is resolved with `Rights::CREATE`, and must be `Object::Space`, else `WrongType`.
       - Release the CSpace lock before touching the space.
    4. Build `Thread::new_tagged(space.owner().clone(), tag)`, so the credential is the owner's, never the caller's. Then `register` it (`Limit`).
    5. Insert `Cap::new(Object::Thread(th.downgrade()), Rights::SIGNAL)` into the caller's CSpace. `CapError::Full` becomes `NoRoom`; unregister on failure.
    6. Call `publish(th.tid())`. On error, remove the capability and unregister.
    7. Set the FS base from `start.fs_base` and call `user::spawn_thread`.

    It returns `(slot, Arc<Thread>)`.

    **`thread_interrupt(caller, slot, entry)`.**
    - `entry` in `[PAGE_SIZE, USER_TOP)`, else `Invalid`.
    - Resolve with `Rights::SIGNAL`; it must be `Object::Thread`.
    - `Dead` when the weak reference does not upgrade or `exit_status()` is set.
    - Otherwise `interrupt(entry)`.
