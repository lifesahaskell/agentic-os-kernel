  <action>
    Per OD-05 and 02-RESEARCH Pattern 8.

    **ledger.rs (new, `#![deny(unsafe_code)]` inherited, no alloc).**
    - A fixed table of `LEDGER_CLIENTS = 64` entries `{tag, window_start, requests, cycles}`.
    - `admit(tag, now)`:
      - starts a new window for the tag when `now - window_start >= window_cycles`;
      - counts the request, and returns `Verdict::Busy` once `requests` would exceed `limit`;
      - returns `Busy` for an unknown tag when every entry is live in its window;
      - recycles an entry whose window has expired.
    - `charge(tag, cycles)` adds server cycles spent, so the ledger reports both requests and CPU.
    - `now` is a parameter, so the logic is testable with synthetic times. The server supplies the 01-07 TSC read.
    - Doc comment: the key is `IpcArgs.tag` as stamped by the kernel. Tags are chosen only by a Space-capability holder (OD-13), so a client process cannot multiply its own entries.

    **lib.rs.** Add `pub mod ledger;`, and update the crate doc's list of asm modules only if it changes (it does not: no new unsafe).

    **Bin `ledger_srv.rs`.** `recv` on slot 0, then `admit(args.tag, tsc)`:
    - `Admit`: reply `words[0] = 0`, then `charge` the cycles the request took.
    - `Busy`: reply `words[0] = (-EAGAIN) as u64`.
    - Label 0xFFFF replies and exits 0.
    - Arg 1 runs the self-test above instead.

    **ktests (agent.rs test module).** The two tests in `<behavior>`. They live here, not in `ipc.rs`, so this wave-1 plan shares no file with 02-02. Kernel clients are `Thread::new_tagged` threads of a root agent holding a SEND cap to the server's endpoint. The server is spawned with testkit `spawn_image`.
