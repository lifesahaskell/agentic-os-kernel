**As a** procmgr author, **I want to** have Space and Thread capabilities, full process teardown and timers, **so that** processes can be created, signalled and destroyed without leaks.

<objective>
Agent-level teardown and the full leak gate (KERN-08, second half; OD-04 agent level, OD-07, OD-08, OD-19). It covers:
- when a child agent's last process dies, its capabilities are dropped and its carved budgets go back to the parent;
- IPC staging and kernel copy-on-write breaks are charged to the right process;
- a torn-down process's timers are dropped;
- the kernel counters and a free-frame probe show the 10,000x loops are flat.

This plan is a DRAFT written against the post-01-07 tree (OD-10), on top of 02-02 and 02-04 to 02-06. Re-check after 01-07 lands:
- Task 2: the ring-3 IPC test bins used for staging (`bulk`, `bulk_srv`, or their 01-07 replacements);
- Task 3: the `yielder` bin used to move the activation pin before each frame probe.

Re-check after 02-02 lands: the `Armed` fields in `kernel/src/ipc/timer.rs` that Task 3 filters on.

Purpose: success criterion 3. Without the agent level, every child agent keeps the memory and CPU its parent carved for it forever. Without the ledger conversion, a process's kernel-side copy-on-write pages leak into its agent's budget.

    - `Agent` gains:
      - `parent: Option<Weak<Agent>>`;
      - `spaces: AtomicUsize`, whose top bit `RETIRED` is the retired flag;
      - `carve_returned: AtomicBool`.
    - `build` takes the parent `Weak`.

    - `leave_space()` decrements. When the count reaches zero on an agent with a parent, it compare-exchanges 0 to `RETIRED`; when that succeeds, it calls `retire()`. A root agent (no parent) never retires (OD-19).
    - `retire()`:
      1. Takes the drained capabilities out under the CSpace lock.
      2. Drops them after releasing it: dropping a capability can drop a Space or an Agent.
      3. Calls `return_carve()`.
    - `return_carve()` runs once, guarded by swapping `carve_returned`. It upgrades the parent, then:
      - `uncharge_pages(mem_limit_pages)`;
      - subtracts `cpu_quota_ticks` from the parent's carved ticks.

      A gone parent means there is nothing to return.
    - `impl Drop for Agent` calls `return_carve()`, so a child that never had a counted space still returns its carve.
    - `LIVE_AGENTS`: an `AtomicUsize` raised in `build` and lowered in `Drop`, read by `live_agents()`.
    - `is_retired()` and `cpu_carved_ticks()` are public getters.
    - Delete the shortcut comment at line 143: the carve now comes back, which is what that comment deferred.
    - `Payer` gains `fn uncharge_pages(&self, pages: usize)`:
      - for `Agent`, the inherent method;
      - for the `Arc` blanket impl, delegation.
