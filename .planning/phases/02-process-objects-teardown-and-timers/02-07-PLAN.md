**As a** procmgr author, **I want to** have Space and Thread capabilities, full process teardown and timers, **so that** processes can be created, signalled and destroyed without leaks.

<objective>
Agent-level teardown and the full leak gate (KERN-08, second half). It implements D-01 (agent level), D-02, D-03, D-04, the 02-07 half of D-05 and D-07, D-06 (through 02-11's probe), D-08 and D-09, all signed off in 02-CONTEXT.md. It covers:
- when a child agent's last counted Space dies, the agent drains and closes its CSpace and stops accepting Spaces and children at once (D-01, D-02); it returns its carved budgets to the parent only when its own children count is zero, and the return cascades upward (D-08);
- IPC staging, kernel copy-on-write breaks and `Space::from_clone`'s node charges are all charged to the right process (D-04, D-05, D-07);
- futex lookup returns the real errno of a failed copy-on-write break and never panics on a user address (D-05, D-09);
- a torn-down process's timers are dropped;
- the kernel counters are the primary leak check on both 10,000x loops, and 02-11's free-frame probe is a gate that fails the loop when it is low by more than one measured process footprint (D-03, D-06).

The tree this is written against: Phase 1 is complete (OD-10), and 02-02, 02-04, 02-05, 02-06 and 02-11 land first. Re-check before Task 2 that the ring-3 IPC test bins used for staging (`bulk`, `bulk_srv`) still exist under `userland/`, and before Task 3 the `Armed` fields in `kernel/src/ipc/timer.rs` (from 02-02) that `drop_space` filters on.

Purpose: success criterion 3. Without the agent level, every child agent keeps the memory and CPU its parent carved for it forever. Without the ledger conversion, a process's kernel-side copy-on-write pages leak into its agent's budget. Without the probe gate, every leak check reads counters the teardown code itself maintains.

    Per D-01 (agent level: the CSpace is drained, derived copies held by others survive, nothing is revoked), D-02 (auto-retire at the last counted Space; roots never retire; no pin count) and D-08 (the carve returns only at zero children, cascading upward), all in 02-CONTEXT.md, and OD-14 / OD-19 (adopted spaces never count).     **cap.rs.**
    - `CSpace` gains `closed: bool`, false in `new`.
    - `live()` returns the occupied-slot count, `slots.len() - free.len()`.
    - `drain(&mut self) -> Vec<Cap>` takes every capability out and clears both vectors.
    - `close(&mut self)` sets `closed`. `room()` returns 0 when closed, and `insert` on a closed CSpace is `CapError::Full`, so a retired agent cannot be refilled into a reference cycle.

    **agent.rs: state.**
    - A private `enum Stage { Live, Retiring, Retired }` and a private `struct Life { stage: Stage, spaces: usize, children: usize, carve_returned: bool }`.
    - `Agent` gains `life: SpinLock<Life>` and `parent: Option<Weak<Agent>>`. `build` gains a `parent_link: Option<Weak<Agent>>` argument; `new_root` passes `None`.
    - `AgentError` gains `Retired`. In syscall.rs, `From<AgentError> for Errno` maps `AgentError::Retired => Errno::ESRCH`: the process the call names is gone.
    - Lock rule, in the doc comment on `Life`: `life` is taken before `cspace`, and no code holds `life` while it drops capabilities or calls into the parent.
    - `LIVE_AGENTS`: an `AtomicUsize` raised in `build` and lowered in `Drop`, read by `pub(crate) fn live_agents()`.
    - `is_retired()` is true from `Retiring` on. `cpu_carved_ticks()` is a public getter.

    **agent.rs: methods.**
    - `spawn_child` takes `self: &Arc<Self>`, so it can record `Arc::downgrade(self)` in the child's `parent`. Update callers only where method-call auto-ref does not already cover them (the current callers are in agent.rs, cap.rs, ipc.rs, user.rs, lib.rs and sched.rs, and all call it on an `Arc<Agent>`).
      1. Under `life`: if the stage is not `Live`, return `Err(AgentError::Retired)`; otherwise raise `children`.
      2. Then derive the grants, carve the ticks and charge the pages as today.
      3. Every error after step 1 calls `self.child_gone()` before returning, so the count stays exact.
    - `enter_space() -> Result<(), AgentError>`: under `life`, `Live` raises `spaces`; any other stage is `Err(AgentError::Retired)`.
    - `leave_space()`: under `life`, lower `spaces`. If it reaches 0, the stage is `Live` and `parent` is `Some`, set `Retiring`. Release `life`, then call `retire()` only when this call set `Retiring`. A root agent (no parent) never retires (D-02).
    - `retire()`:
      1. In its own scope, lock `cspace`, take `drain()`, call `close()`, release the lock.
      2. Drop the drained capabilities after the lock is released: dropping one can drop a Space or an Agent, which can re-enter this agent through `child_gone`.
      3. Call `finish_if_childless()`.
    - `finish_if_childless()`: under `life`, when the stage is `Retiring`, `children` is 0 and `carve_returned` is false, set `Retired` and `carve_returned`. Release `life`, then call `return_carve()` only when this call made the change. The flag is set under the lock, so the carve returns at most once whoever calls first.
    - `return_carve()`: upgrade `parent`. If it upgrades, call `parent.uncharge_pages(mem_limit_pages)`, subtract `cpu_quota_ticks` from the parent's `cpu_carved_ticks` with `fetch_sub`, then call `parent.child_gone()`. A parent that no longer upgrades has nothing to return to.
    - `child_gone()`: under `life`, lower `children`; release `life`, then call `finish_if_childless()`. This is the D-08 cascade: a grandchild's return can finish its parent's retire, which returns that carve one level further up.
    - `impl Drop for Agent`: lower `LIVE_AGENTS`. If the agent has a parent, `carve_returned` is false and `children` is 0, return the carve, so a child that never had a counted space still returns its budget. A child dropped while it still has children keeps its carve unreturned: a leak toward its parent, never a double spend.
    - Derived copies the agent handed to others are not touched anywhere in this flow (D-01). Only its own CSpace is drained.
    - Delete the shortcut comment at line 145 above `spawn_child`: the carve now comes back, which is what that comment deferred.

    **space.rs.** 02-06's constructors funnel into a private `Space::build(vm, owner, counted, dying)`, and the rule is: do the fallible work first and call `owner.enter_space()` last, so a failed constructor never touches the count and never retires a fresh child.
    - `Space::new(vm, owner)` calls `enter_space()`. On `Ok`, the space is counted. On `Err`, it is built with `dying` set and `counted` false, so `register` refuses with `Dead`.
    - `Space::from_image(img, owner)` returns `Err(AgentError::Retired)` before charging anything when `owner.is_retired()`. It then charges the image as 02-06 does, and calls `enter_space()`. A refusal at that point (the owner retired meanwhile) uncharges the image and returns `Err(AgentError::Retired)`.
    - `Space::from_clone(parent, range, owner)` returns `Err(CloneError::Budget)` before cloning when `owner.is_retired()`. It then clones through the `Tally`, and calls `enter_space()`. A refusal drops the child `VmSpace` and uncharges the tally, then returns `Err(CloneError::Budget)`. Its doc comment says why: D-07 fixes `CloneError`'s variants, so a retiring owner surfaces as ENOMEM.
    - `Space::adopt` passes `counted` false and never calls `enter_space`.
    - `teardown` calls `owner.leave_space()` last, after the ledger uncharge, when `counted`.
    - `impl Drop for Space` runs `teardown` when it has not run yet, so a space dropped before any thread ran uncharges its image and leaves its count.
