**As a** procmgr author, **I want to** have Space and Thread capabilities, full process teardown and timers, **so that** processes can be created, signalled and destroyed without leaks.

<objective>
Send exit and exception notifications to a per-process endpoint, naming the thread by tid and tag (KERN-10). Faults become a kernel-made call whose reply is the verdict (OD-06), which retires the Phase 1 reply side-channel and the 01-05 per-thread handler (OD-17).

This plan is a DRAFT written against the post-01-07 tree (OD-10), on top of 02-04's `Space`. Re-check after 01-07 lands:
- Task 2: the four exception ktests in `kernel/src/user.rs` as 01-07 ported them to the `cow_writer` and `ud2` bins, and the read-only data-page helper the port of `write_to_read_only_page_is_a_fault_not_cow` uses.
- Task 1: `libsys::test_page()` (U-04) is how `fault_sibling` touches the test page. If 01-07 named it differently, use that name, and add no new `unsafe`.
- Task 3: the post-02-04 fuzz `targeted` array and `numbers` list.

Decisions this plan rests on:
- OD-06: note shape and verdict.
- OD-17: one destination.
- OD-18: no self-redirect after set.
- The 0x107 row, the label range and the NOTE_EXIT kinds, all in `02-OPEN-DECISIONS.md`.

Purpose: procmgr learns that a child faulted or exited and which thread did it, without the kernel handing it a capability. 02-06's kill path sends the fifth kind (killed) through the same sender.

Output:
- the `Space` notify endpoint, `note_exit`, the note path in ipc.rs, the fault `call` in `deliver`;
- `SYS_SPACE_NOTIFY`;
- bin `fault_sibling`;
- ktests `note_exit_*`, `note_fault_*`, `space_notify_*` and the four ported exception tests.
</objective>
