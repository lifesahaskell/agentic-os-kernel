Output: the `tools/aok-launch` crate (bin + lib, pinned toolchain, three pinned deps, committed `Cargo.lock`), a working `run`/`freeze`/`thaw`/`kill` for the happy path, the delegated-scope test fixture, and `spawn`/`lifecycle` integration tests that run green inside one `systemd-run --user --scope -p Delegate=yes` scope.
